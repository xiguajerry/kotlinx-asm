# kotlinx-asm

## What is it?

This project aims to rewrite [ASM](https://asm.ow2.io/) on Kotlin Multiplatform 
and try to provide more idiomatic interfaces compared to the original library.

This is a hobby project, so there is no guarantee of timely maintenance. Use this at your own risk.
